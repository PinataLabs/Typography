## Fonts

The licence of the library does not cover fonts. Each font has its own licence. Check that it allows
the use that you plan, for example embedding the font in an application or in documents.

The fonts in the repository's test folders are there only to test the library. Do not take them
from there for your own use; get each font from its publisher, with its licence.
